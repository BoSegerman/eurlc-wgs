EURLC-WGS -- whole genome sequencing analysis for Campylobacter, Salmonella,
E. coli and Listeria (Illumina reads or assemblies)

USAGE
    cd <data-folder>
    eurlc-wgs [options]

    or, from anywhere:
    eurlc-wgs datadir=<data-folder> [options]

    Results go to <data-folder>/eurlc-wgs, or to exactly the folder given
    with outdir=. In this text that folder is <out-folder>.

    Arguments are written name=value or --flag. For the four arguments
    that take a folder or a file (datadir, outdir, database, configfile) a
    space works as well as "=", so that the shell can complete the path
    with the Tab key:
        eurlc-wgs datadir /data/run192        same as datadir=/data/run192
    An argument may be given only once.

    --qc-screen                  Instead of the full analysis: a quick check
                                 of the raw reads only (Q30 coverage, species,
                                 other genus, read length), with a
                                 traffic-light report in
                                 <data-folder>/eurlc-wgs_qcscreen/

INPUT AND OUTPUT
    datadir=<data-folder>        Folder with FASTQ (paired or single) and/or
                                 FASTA files (default: the current folder)
    outdir=<out-folder>          Write results to exactly this folder
    database=<database-folder>   Database folder (default ~/eurlc-wgs_db)
    configfile=<configfile>      Settings file. A name without a folder is
                                 looked for in <database-folder>; a path is
                                 used as given
                                 (default <database-folder>/eurlc-wgs.config)
        configfile=default       use no settings file (built-in values)
    --write-configfile[=<configfile>]
                                 Write the current settings to a file and
                                 exit: <database-folder>/eurlc-wgs.config, or
                                 the name (in <database-folder>) or path given
    --recursive                  Also look for input files in subfolders
    --fastq                      Analyse only the FASTQ files of the folder
    --fasta                      Analyse only the FASTA files of the folder

    Illumina names lose their sample number and lane in the sample name
    (PT43_S12_L001_R1_001.fastq.gz -> PT43); one sample on several lanes is
    merged before the analysis.

AN EXISTING OUTPUT FOLDER
    (asked by default)           overwrite, resume or stop
    --resume                     Continue: reuse finished results, run what is
                                 missing or failed
    overwrite=yes | no           Overwrite without asking / stop
                                 (--overwrite = overwrite=yes)
    rerun=<step>[,<step>...]     In an existing folder (implies --resume): run
                                 these steps again, and every step that depends
                                 on them. Step names: eurlc-wgs --list-steps
    summarize                    Re-evaluate QC with the current thresholds
                                 and rebuild the report and data/rundata.json
                                 (no tools are run)

WHAT IS ANALYSED
    enable=<tool|species>[,...]  Switch tools on, e.g. enable=sistr or
                                 enable=Salmonella (all its typing tools)
    disable=<tool|species>[,...] Switch tools off, e.g. disable=bakta
    <tool>.<setting>=<value>     One setting of a tool, e.g.
                                 fastp.arguments="--length_required 50"
                                 spades.timeout=4h
    <setting>=<value>            A general setting, e.g. threads=8

    --list-tools                 The tool names (and whether each is on), and
                                 the step names for rerun=. A tool is a
                                 program with its settings; a step is one
                                 stage of the analysis, usually named after
                                 its tool (--list-steps shows the same)
    infotool=<tool>              A tool's settings and installation

    All settings, with their built-in values, are listed in
    <database-folder>/eurlc-wgs.config.

RUNNING
    threads=<n>                  Threads per tool
    parallel_mode=on             Run several samples/steps at once within
                                 max_threads=<n> / max_ram_gb=<n>
                                 (default: what the computer has)
    --assume-yes                 Answer installation questions with yes
                                 (never: overwriting results or a config file)
    --verbose                    More detail in the log
    --no-color / --color         Coloured screen output off / on

    To pause, continue or stop a run that is going, write the word pause,
    resume or terminate to a file in <out-folder>/control/ from another
    terminal (the file name does not matter):
        echo pause     > <out-folder>/control/cmd
        echo resume    > <out-folder>/control/cmd
        echo terminate > <out-folder>/control/cmd
    Running steps are finished first; terminate then ends the run, and
    --resume continues it later.

INSTALLATION
    --setup                      Install or complete the installation: tool
                                 environments, databases and the cgMLST
                                 schema of each species of the installation.
                                 Installs only what is missing
    --setup species=<list>       Add species to the installation:
                                 campylobacter, salmonella, ecoli, listeria
                                 (comma-separated), or all
    --installation-check         Does this installation give the right
                                 results? Runs the check sets that came with
                                 the installation (a few samples with known
                                 results) and compares. Nothing needs to be
                                 named: without a name every set is run
    --list-schemas               The cgMLST schemas that are installed, and
                                 how to install others

    For whoever looks after an installation or a validated method (single
    tools, freezing databases, sealing a configuration, making a check set,
    comparing with validation datasets and earlier runs):
        eurlc-wgs --help-admin

INFORMATION
    --help                       This text
    --help-admin                 Installation, maintenance and validation
    --manual                     Where the user manual is on this computer
                                 (one HTML file for the web browser, and a
                                 PDF)
    --version                    The pipeline version
    --versions                   The pipeline and every tool's version

EXIT CODES
    0 finished   1 error   2 nothing to analyse   3 finished, a sample was
    abandoned   4 interrupted   5 finished, a step failed or timed out
    6 stopped with terminate

FILES IN THE OUTPUT FOLDER
    report/main_report.html      The report
    report/tables/               Result tables, and the results fingerprint
                                 (eurlc_results_fingerprint.json.gz)
    data/rundata.json            All results of the run, for scripts
    log/log.txt                  Full log (search "EURLC-WGS RUN")
    log/run_summary.txt          Summary of the last run
    log/run_status.json          Status for scripts and GUIs
    log/events.jsonl             One line per step started/finished

COMPANION TOOLS (installed with the pipeline; --help on each)
    eurlc-wgs-inspect            Look into output folders: inventory, extract a
                                 small package, summarize many runs, compare
                                 runs (repeatability, after an update)
    eurlc-validate               Compare any pipeline's results with an EURL
                                 validation dataset
    eurlc-cgmlst-compare         Why two cgMLST results of the same isolate
                                 differ (profiles, schemas)

EXAMPLES
    cd /data/run192; eurlc-wgs
    eurlc-wgs datadir=/data/run192 threads=8
    eurlc-wgs datadir /data/run192 outdir /analysis/run192
    eurlc-wgs datadir=/data/run192 --qc-screen
    eurlc-wgs outdir=/analysis/run192 --resume
    eurlc-wgs outdir=/analysis/run192 --resume skesa.timeout=6h
    eurlc-wgs outdir=/analysis/run192 rerun=sistr enable=sistr
    eurlc-wgs outdir=/analysis/run192 summarize

this computer (HTML and PDF); online it is docs/eurlc-wgs-user-manual.md at
